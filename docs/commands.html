Commands

All commands start with /mm. Typing /mm alone lists them.

Summary

Command What it does
/mm list Every macro in the collection this character follows: have, ready (spell known, macro not created) or not learned, plus character slots used.
/mm sync Create all missing macros, then open the macro window on the character tab. Never touches existing ones.
/mm sync known The same, but only for macros with a spell you already know.
/mm update Rewrite every existing macro now. Normally automatic.
/mm resync /mm sync plus /mm update: create anything missing, rewrite the rest, open the macro window. Macros stay on your bars.
/mm clear Delete this character's macros whose names appear in any collection for its class.
/mm collections Installed collections, the classes each covers, and the one this character follows.
/mm use <name> Follow that collection on this character.
/mm use default Go back to the default choice.
/mm docs Show this documentation's web address, selected for Ctrl+C; the box closes once you copy.

Details

/mm sync

/mm sync is the once-per-character setup. It creates every macro in the list, known or not, so you can lay out your bars once; macros for spells you don't know yet show a question mark and fill in as you train. It reports anything that didn't fit in your free character slots.

/mm update

/mm update is rarely needed: macros are rewritten automatically when you learn a spell or change your main-hand weapon (after combat, if you're in it). Use it after editing a class file if you don't want to wait.

/mm resync

/mm resync is the command to run after editing a class file or switching collections: it brings the character fully up to date without taking anything off your bars.

/mm clear

/mm clear deletes by name. A character macro is deleted when its name appears in any collection's list for the character's class (Mikey's, Ulako's, ...). Other character macros, such as one called test, are kept, and general (account) macros are never touched. A hand-made macro that happens to share a collection macro's name is deleted. There's no confirmation, and deleted macros come off your bars. See name collisions.

/mm use <name>

/mm use <name> saves the choice for this character only. If the collection doesn't have the character's class, the default choice is used until it does. Switching deletes nothing; follow it with /mm resync, or /mm clear first for a clean switch. See Switching collections.

Nothing that changes macros runs in combat; the addon says so, or waits for combat to end.
