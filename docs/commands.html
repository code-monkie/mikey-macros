Commands

All commands start with /mm. Typing /mm alone lists them.

Summary

Command What it does
/mm list Every macro in the collection this character follows: have, ready (spell known, macro not created) or not learned, plus character slots used.
/mm sync Create the missing macros for the spells you know, by the usual rule, then open the macro window on the character tab. Never touches existing ones.
/mm sync all The same, plus collection macros for spells you haven't learned yet (placeholders).
/mm update Rewrite every existing collection macro now. Normally automatic.
/mm resync /mm sync all plus /mm update: create anything missing, rewrite the rest, open the macro window. Macros stay on your bars.
/mm clear Delete this character's macros whose names appear in any collection for its class.
/mm clear -a Delete all of this character's macros, whatever made them, after a Yes/No popup.
/mm collections Installed collections, the classes each covers, and the one this character follows.
/mm use <name> Follow that collection on this character (default for the Default collection).
/mm use none Follow no collection on this character (Default's macros and generated ones still apply).
/mm auto on / off Auto mode, on by default: a macro for each new class spell this character learns.
/mm docs Show this documentation's web address, selected for Ctrl+C; the box closes once you copy.

Which macro a spell gets

Auto mode (when you learn a spell) and /mm sync (for the spells you already know) use the same rule. For each spell, the first that applies:

  1. The collection you follow has a macro for it: that macro.
  2. The Default collection has one: Default's. Default applies under every collection, wherever the collection you follow has nothing for the spell (or the same macro name).
  3. The spell is excluded for the class (tracking, Eyes of the Beast, Far Sight, mounts, ...): no macro.
  4. Otherwise a generated macro (see auto mode).

A collection macro with several spells is created when the first of them is learned; the others only update it. A spell shouldn't be both excluded and in a macro you follow: if one is, a red conflict: line in chat says so at login.

Details

/mm sync and /mm sync all

/mm sync catches a character up: a leveled character the addon sees for the first time, or one that just switched collections. It creates what auto mode would have made for every spell the character knows (generated macros only while auto mode is on) and never touches macros that already exist.

/mm sync all also creates the collection's macros for spells you don't know yet, so you can lay out your bars once; they show a question mark and fill in as you train. Both report anything that didn't fit in your free character slots.

/mm update

/mm update is rarely needed: collection macros are rewritten automatically when you learn a spell or change your main-hand weapon (after combat, if you're in it). Use it after editing a class file if you don't want to wait.

/mm resync

/mm resync is the command to run after editing a class file: it brings the character fully up to date, placeholders included, without taking anything off your bars.

/mm clear and /mm clear -a

/mm clear deletes by name. A character macro is deleted when its name appears in any collection's list for the character's class (Default's, Mikey's, Ulako's, ...). Other character macros, such as one called test or a generated macro, are kept, and general (account) macros are never touched. A hand-made macro that happens to share a collection macro's name is deleted. There's no confirmation, and deleted macros come off your bars. See name collisions.

/mm clear -a deletes every character macro, hand-made ones too, after a Yes/No popup. General (account) macros are still kept. With /mm sync after it, it's the clean way to switch collections or start over.

/mm auto on / off

Auto mode, per character, on by default. Every new class spell the character learns gets a macro, by the usual rule. A generated macro is shaped by what the game says about the spell:

SpellMacro
harmful/startattack first
harmful, ranged/use [@mouseover,harm,nodead] [] Spell
helpful, ranged/use [@mouseover,help,nodead] [] Spell
toggle (stance, form, aura, auto-repeat, "until cancelled")/use !Spell, so a second press doesn't cancel it
pet-only (Mend Pet, Health Funnel)no targeting

For example, Frostbolt becomes:

#showtooltip
/startattack
/use [@mouseover,harm,nodead] [] Frostbolt
  • Only new spells: a spell counts once, when its first rank (or the unranked spell) is learned; higher ranks don't make another macro. A spell is only ever handled once, even after a talent reset or deleting its macro.
  • Where it starts: a brand-new (level 1) character gets macros for its starting spells. A character that's already leveled when the addon first sees it is left as it is (/mm sync catches it up), and so is everything a character knows when you turn auto mode back on with /mm auto on.
  • Class spells only: the class tabs of the spellbook. The General tab (Attack, racials, professions, mounts), passive spells and pet abilities are skipped.
  • On your bars: if the spell is already on an action button (your starting spells at level 1; on retail, spells the game places for you), the new macro takes its place. Empty buttons are never filled. If a new macro didn't land on a bar, the macro window opens on the character tab so you can drag it on.
  • In chat: new spell macro: ... for each one made, and no macro (excluded): ... once for each excluded spell.
  • Names: the spell's name, or its initials when longer than 16 characters (Blessing of Might becomes BoM); a number is added if the name is taken.
  • Generated macros are yours: the addon never rewrites them, and /mm clear doesn't delete them (/mm clear -a does), so tweak them freely.

/mm auto alone shows whether it's on. Turning it off keeps the macros it made.

/mm use <name>

New level-1 characters start on the Default collection. /mm use <name> picks another for this character only (it must have a list for the character's class), /mm use default goes back to Default, and /mm use none follows nothing (Default's macros and generated ones still apply). /mm use alone lists the collections. Switching deletes nothing: the old collection's macros are kept but no longer updated. For a clean switch, /mm clear -a, then /mm sync. See Switching collections.

Nothing that changes macros runs in combat; the addon says so, or waits for combat to end.
