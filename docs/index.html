mikey-macros

Per-character class macros that build themselves as you level. Write a class's macros once, in full, the way you want them at max level. On each new character the addon creates them all, then keeps every macro trimmed to the spells that character actually knows. Learn a spell and the macros that use it update on their own.

Built for WoW: Forever; developed and tested on Classic Era (1.15.9) and retail (12.1.5).

Quick start

  1. Put the mikey-macros folder in Interface\AddOns and restart the game.
  2. On a character, run /mm sync. The macro window opens on the character tab with the class's macros; keys you haven't learned yet show a question mark.
  3. Drag the macros onto your action bars.
  4. Play. Each macro fills in as you train its spells.

To follow someone else's set on a character: /mm collections, then /mm use <name> and /mm resync. In game, /mm docs gives you this page's address to copy.
