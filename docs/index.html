mikey-macros

Per-character class macros that build themselves as you level. Write a class's macros once, in full, the way you want them at max level. On any character that follows them, the addon creates them all, then keeps every macro trimmed to the spells that character actually knows. Learn a spell and the macros that use it update on their own.

Out of the box, auto mode gives each class spell a macro as you learn it, with mouseover targeting, /startattack on attacks, and safe versions of crowd control, stealth and resurrection.

Built for WoW: Forever; developed and tested on Classic Era (1.15.9) and retail (12.1.5).

Quick start

  1. Put the mikey-macros folder in Interface\AddOns and restart the game.
  2. Play. Auto mode is on: each class spell you learn gets its own macro. At level 1 your starting spells become their macros right on the bar, and an Attack macro goes on bar 1, button 9; after that, the macro window opens so you can drag new ones on.

Already leveled? A character the addon first sees above level 1 is left as it is; /mma sync gives it macros for everything it knows.

Want hand-written macros? Follow a collection: /mma collections to see what's installed, /mma use <name>, then /mma sync. /mma sync all creates the whole class set at once (unlearned keys show a question mark and fill in as you train). In game, /mma docs gives you this page's address to copy.
