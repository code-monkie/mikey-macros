How it works

Lifecycle

  1. Setup (once per character): /mm sync creates every macro in the collection the character follows, as character-specific macros. Drag them onto your bars.
  2. Trimming: each macro is written with only the spells the character knows (see trimming rules). Fall-through lines and #showtooltip icons therefore always work, and a macro with nothing known yet shows a question mark.
  3. Automatic updates: when you learn a spell or change your main-hand weapon, the macros are rewritten. Changes are batched (half a second) and wait for combat to end.
  4. Rewriting edits a macro in place, so it keeps its place on your bars.

The addon owns its macros

An edit made in the in-game macro window is overwritten the next time the macro is rewritten. Make permanent changes in the collection's class file (see the Collections guide). Renaming a macro in game takes it out of the addon's hands. General (account) macros are never touched.

Spell detection

The addon reads the spellbook, by name, for spells that are actually learned (not future or off-spec spells). It uses retail's C_SpellBook API where present and the Classic spellbook API otherwise, so the same files work on Classic Era, WoW: Forever and retail.

Saved data

Only one thing is saved: the collection chosen with /mm use, per character (MikeyMacrosCharDB). The macro lists live in the addon's files; the trimmed macros live in the game's own macro storage.

Performance

A few kilobytes of data, no OnUpdate, no timers. Work happens only when spells or the main-hand weapon change: one spellbook scan and a string comparison per macro.

Limits

  • Character macros: 30 per character on Classic Era and retail. WoW: Forever is likely the same but not confirmed yet (/dump MAX_CHARACTER_MACROS). /mm sync reports anything that didn't fit.
  • 255 characters per macro body, 16 per name.
  • Macros can't be created or changed in combat.

Troubleshooting

  • A key shows "?": you don't know any of its spells yet. Expected.
  • A macro didn't update after training: /mm update. If it still doesn't, check the spell's name in spells matches the spellbook exactly.
  • A new class file isn't picked up: it must be listed in mikey-macros.toc, and a new file needs a full game restart.
  • A hand-made macro disappeared on /mm clear: its name matched a collection macro; see name collisions.
  • Lua errors: install BugGrabber and BugSack and check what they caught.
